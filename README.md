# Multi-Branch Network Design — Cisco Packet Tracer

A complete two-branch company network designed and configured in Cisco Packet Tracer as a hands-on CCNA-level project.

## Topology overview
- Two branch sites, each with 4 switches and around 16 end devices (PCs, IP phones, printers)
- Departments separated into VLANs: IT, Office, HR and Management
- Inter-VLAN routing, per-VLAN DHCP, NAT towards the WAN, and ACLs controlling traffic between departments

## Key configurations
- VLANs and 802.1Q trunking
- Spanning Tree with planned root bridge placement
- Port Security with sticky MAC addresses
- DHCP pools per department
- NAT (PAT) for shared internet access
- Standard and extended ACLs
- Step-by-step verification with ping, traceroute and show commands

## Tools
- Cisco Packet Tracer

The .pkt project file will be added so anyone can download and explore the topology.
